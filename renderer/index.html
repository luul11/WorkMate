乐伴WorkMate

一只住在屏幕角落的狗：记得你答应过的事，你专注时不打扰。

  • 数据只在你自己电脑上。没有服务器、没有账号，存在本机的一个 JSON 文件里。
  • 它只看你在用什么软件。读的是前台进程名（比如 wps.exe），读不到窗口里的内容。
  • 关掉主窗口它还在后台记录。要真退出，右键桌宠 → 退出 乐伴WorkMate。

不收集、不上传、不需要登录。随时可以在「设置」里导出或清空全部数据。

它每小时自己出门一趟，回来讲一段。楼下会碰见别的狗：投缘就交个朋友，不对付就打一架；有时候几只会凑一桌打阿瓦隆或狼人杀。偶尔也和当天用过的软件打一架。

记忆分层

三层逐级压缩：一天的采样压成日记，一批日记压成月度摘要，月度摘要再压成一句印象。 每层只读下一层的数据，全部是本地统计，没有模型参与。

短期 · 按天 分钟采样 → 一天一段话

取今天的活跃时长、工作块数、类别占比，拼成一段话。计算过程可预期，同一份数据写出来永远一样。

中期 · 按月 每天日记 → 一个月一段

把整月每天的数据加起来：有效天数、日均在线、时间主要花在哪两类。做完之后，这个月的日记就可以删了。

关于

乐伴WorkMate 是一个住在桌面角落的小助理，在工作和生活中感受黄毛拉布拉多犬（乐乐）的陪伴。

它每分钟读一次当前前台窗口的进程名，把这段时间记进你今天的账里：几点到几点在写代码、看文档、刷网页， 还是锁着屏在休息。

纯单机应用，技术栈是 Electron；数据写在本机三个文件里，没有账号，不联网。

它现在会做的事

  • 读前台窗口，按进程名归到编程、文档、浏览、运维、会议、休息、本应用、其他这八类
  • 记时间账：今日总时长、类别去向、工作块时间轴，满一分钟自己就长出来
  • 拆待办：「后天去深圳出差，在此之前订票」会拆成一条日程加一条前置任务
  • 管提醒：静默时段、半小时预算、可顺延、逾期汇总
  • 存记忆：日记、月度摘要、长期印象，三层逐级压缩，全是本地统计
  • 养狗：它每小时自己出门一趟；点「远行冒险」能送它走一到三小时，每半小时带一件事回来
